# dsh-wsl-workspace

DeepSeek Harness 插件：列出 WSL 发行版并校验可用于 DeepSeek Harness 的 Linux 工作区路径。

配套 **[dsh-wsl-kit](https://github.com/173787247/dsh-wsl-kit)**。

[English → README.md](./README.md)

## 安装

```sh
dsh plugin --profile web add github:173787247/dsh-wsl-workspace
```

重启 `dsh web` 并开**新**会话。工具名：`wsl_workspace`。
